**Functional Data Analysis and FPCA Using Fourier and B-Spline Bases**

This project explores Functional Data Analysis (FDA) and Functional Principal Component Analysis (FPCA) using Canadian precipitation data from 13 weather stations.

Two basis representations are investigated:

* Fourier basis
* B-spline basis using the Cox–de Boor algorithm

The project includes manual implementations, penalized smoothing, Generalized Cross-Validation (GCV), and FPCA, with comparisons to R package implementations.
